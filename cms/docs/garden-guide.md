# คู่มือปลูกทานตะวัน (สำหรับผู้ร่วมงาน)

หย่อนเมล็ดพร้อมคำอธิษฐาน ผสมปุ๋ยสูตรของคุณเอง แล้วรอดูดอกบานพร้อมกันทั้งสวน
ไม่ต้องเข้าสู่ระบบ ทำบนมือถือได้

> คู่มือฝั่งผู้ดูแล อยู่ที่ [garden-admin-guide.md](./garden-admin-guide.md)

## เปิดลิงก์ไหน

| หน้า | ลิงก์ | ใช้ทำอะไร |
| --- | --- | --- |
| ปลูก | `/garden/plant/<slug>` | หย่อนเมล็ด |
| แปลงรวม | `/garden/<slug>` | ดูทุกต้น นับถอยหลัง และของตกแต่งที่ปลดล็อคแล้ว |
| สวนของฉัน | `/garden/mine/<slug>` | ต้นทั้งหมดของคุณ และใส่ปุ๋ยลับ |
| คำอธิษฐานทั้งหมด | `/garden/cards/<slug>` | เปิดหลังวันที่ดอกบาน |

## ปลูก

1. กรอกชื่อ (ไม่เกิน 60 ตัวอักษร) และคำอธิษฐาน (ไม่เกิน 300 ตัวอักษร)
2. เลือกปุ๋ย 2 ถุงจาก 6 ถุง กดถุงที่เลือกซ้ำเพื่อยกเลิก
3. เลื่อนแถบแบ่งสัดส่วน หรือพิมพ์ตัวเลข สองถุงรวมกันเป็น 100% เสมอ
4. กด **หย่อนเมล็ด** จะได้ **บัตรเมล็ดพันธุ์** บันทึกเป็นรูปหรือคัดลอกลิงก์ได้

หน้าตาดอกขึ้นกับสูตรปุ๋ย และเป็นความลับจนถึงวันที่ดอกบาน ปลูกได้หลายต้น กด **ปลูกอีกต้น** แล้วปุ๋ยเดิมยังเลือกไว้ให้

## สวนของฉันและลิงก์สวน

สวนของคุณผูกกับเบราว์เซอร์ที่ใช้ปลูก ต้นแรกที่ปลูกจะได้ **ลิงก์สวนของฉัน** ให้คัดลอกเก็บไว้
ใช้เปิดสวนเดิมในเครื่องอื่น อย่าส่งให้คนอื่น เพราะใครมีลิงก์นี้ใส่ปุ๋ยลับให้ต้นของคุณได้
ถ้าทำลิงก์หาย แจ้งผู้ดูแลให้สร้างลิงก์ใหม่

## ปุ๋ยลับ

ได้ด้วย token จากการโดเนทเท่านั้น

1. ที่สวนของฉัน กด **ใส่ปุ๋ยลับ** ใต้ต้นที่ต้องการ
2. กรอกชื่อบัญชีที่ใช้ตอนโดเนท แล้วกด **ดู token**
3. เลือกทานตะวันบนชั้น (ปัดหรือกดลูกศรเพื่อเปลี่ยนหน้า) ทุกแบบราคาเท่ากัน
4. กด **ใช้ปุ๋ยนี้** แล้ว **ยืนยัน**

**ใส่แล้วเปลี่ยนแบบไม่ได้ และใส่ได้ต้นละครั้ง** คุณจะเห็นแบบที่เลือกในสวนของฉันทันที
คนอื่นเห็นพร้อมกันในวันที่ดอกบาน ถ้าแบบนั้นมีรูปหน้า รูปหน้าที่สุ่มได้จะเฉลยในวันที่ดอกบานด้วย

## เจอข้อความนี้ ทำอย่างไร

| ข้อความ | ทำอย่างไร |
| --- | --- |
| ไม่พบสวนนี้ | ขอลิงก์จากผู้ดูแลอีกครั้ง |
| ตอนนี้ยังไม่เปิดรับการปลูก | รอผู้ดูแลเปิด หรือดูแปลงรวมไปก่อน |
| ปลูกถี่เกินไป | รอสักครู่แล้วลองใหม่ |
| ไม่พบสวนของคุณ ลิงก์อาจถูกเปลี่ยนแล้ว | ขอลิงก์สวนของฉันใหม่จากผู้ดูแล |
| ไม่พบชื่อบัญชีนี้ | พิมพ์ชื่อบัญชีให้ตรงกับที่ใช้ตอนโดเนท |
| Token ไม่เพียงพอ | โดเนทเพิ่ม แล้วรอผู้ดูแลตรวจสลิปก่อน token จึงจะเข้า |
| ต้นนี้ใส่ปุ๋ยลับแล้ว | ต้นละครั้งเท่านั้น ปลูกต้นใหม่ถ้าอยากได้แบบอื่น |
