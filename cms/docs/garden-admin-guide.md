# คู่มือดูแลสวนทานตะวัน (สำหรับผู้ดูแลระบบ)

ทำที่หลังบ้าน เมนู **สวนทานตะวัน** คู่มือนี้ครอบคลุมตั้งแต่เปิดสวนใหม่จนถึงวันที่ดอกบาน

> คู่มือฝั่งผู้ร่วมงาน (วิธีปลูกและใส่ปุ๋ยลับ) อยู่ที่ [garden-guide.md](./garden-guide.md)

## ก่อนเริ่ม: ฐานข้อมูลต้องพร้อม

```bash
cd cms && npm run prisma:deploy      # prisma migrate deploy
```

เซิร์ฟเวอร์ที่รัน Prisma ไม่ได้ ใช้สคริปต์สำรองแทน (รันซ้ำได้)

```bash
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f deploy/garden-manual.sql
```

แล้ว deploy API ตัวใหม่ด้วย ไม่งั้น endpoint ที่เว็บไซต์เรียกจะยัง 404
สิทธิ์ที่ใช้คือ `garden.view` (ดู) และ `garden.manage` (แก้ไข ดูแลต้น และเปิดสวน)

## เปิดสวนใหม่ เจ็ดขั้น

1. **กด "สร้างสวน"** ใส่ชื่อ slug และวันเวลาที่ทุกต้นบาน (ปิดรับปลูกพร้อมกันเวลานั้น)
2. **แท็บ ปุ๋ย** เพิ่มปุ๋ย 6 ถุง (ชื่อ สี รูปถุง) ผู้ร่วมงานเลือกได้ 2 ถุง จึงมีทั้งหมด 15 คู่
3. **แท็บ แบบดอกทานตะวัน** อัปโหลดทุกแบบเป็น PNG พื้นใส ขนาดและมุมมองเดียวกัน
   (แนะนำ 1024×1536 โคนต้นอยู่กึ่งกลางล่าง)
   - เปิด **ชั้นปุ๋ยลับ** ให้แบบที่ขายด้วย token ลำดับในตารางคือลำดับบนชั้น
   - เปิด **ใส่รูปหน้า** ให้แบบบนชั้นที่ต้องการรูปหน้า แล้วกด **กำหนด** เพื่อคลิกวางวงกลมบนรูป
4. **แท็บ ตั้งค่างาน** เลือก **แบบดอกตั้งต้น** (ข้อนี้ข้ามไม่ได้ ไม่งั้นเปิดรับปลูกไม่ได้)
   ผูก **โปรเจกต์โดเนท** ที่มีอยู่แล้ว และตั้ง **ราคาปุ๋ยลับ** (token ต่อแบบ เท่ากันทุกแบบ)
5. **แท็บ สูตร** กดช่องในตาราง 6×6 เพื่อเพิ่มสูตรของปุ๋ยคู่นั้น
   ตั้งช่วง % ของถุงแรกด้วยแถบเลื่อน (ถุงที่สองตามอัตโนมัติ) แล้วเลือกแบบดอก
   แถบสีด้านบนบอกว่าทุกสัดส่วนจะได้ดอกแบบไหน ส่วนสีเทาคือแบบดอกตั้งต้น กด **บันทึกสูตรทั้งหมด** เมื่อเสร็จ
6. **แท็บ ช่วงเติบโต / คลังรูปหน้า / ของตกแต่ง** ใส่ตามต้องการ
   - ช่วงเติบโต: รูปที่ทั้งแปลงแสดงก่อนวันเปิดผล ถ้าไม่ใส่ เว็บไซต์ใช้รูปวาดตั้งต้น
   - คลังรูปหน้า: รูปที่ระบบสุ่มใส่ในดอกจากชั้นปุ๋ยลับ
   - ของตกแต่ง: ปลดล็อคเมื่อยอดของโปรเจกต์โดเนทถึงที่ตั้งไว้ (นับเฉพาะรายการที่ตรวจแล้ว)
7. **ตรวจกล่อง "ลิงก์สำหรับผู้ร่วมงาน"** ต้องขึ้น "พร้อมเปิดรับปลูก" แล้วจึงแจกลิงก์

### ตรวจก่อนแจกลิงก์

- ใช้ **ทดสอบสูตร** ท้ายแท็บสูตร เลือก 2 ถุงแล้วเลื่อนดูผล (ใช้สูตรที่บันทึกแล้ว)
- ปลูกต้นทดลองจากหน้าปลูกจริง แล้วลบด้วย **ลบต้นทั้งหมด** ในหน้าต้นทานตะวัน
  (หมายเลขต้นที่ใช้ไปแล้วจะไม่ถูกนำกลับมาใช้ ต้นจริงจะเริ่มต่อจากนั้น)

## ระหว่างเปิดรับปลูก

| ทำอะไร | ที่ไหน | หมายเหตุ |
| --- | --- | --- |
| ซ่อนต้นที่ไม่เหมาะสม | ต้นทานตะวัน → ซ่อน | ย้อนกลับได้ ช่องในแปลงยังว่างไว้ |
| ลบต้น | ต้นทานตะวัน → ลบ | ลบต้นทั้งหมดไม่ได้ถ้ามีคนซื้อปุ๋ยลับแล้ว |
| คนปลูกเปิดสวนของตัวเองไม่ได้ | ต้นทานตะวัน → เพิ่มเติม → สร้างลิงก์สวนของฉันใหม่ | ลิงก์เดิมใช้ไม่ได้ทันที ส่งลิงก์ใหม่ให้เจ้าของทางแชตส่วนตัว |
| แก้แบบดอกปุ๋ยลับกรณีพิเศษ | ต้นทานตะวัน → เพิ่มเติม → แก้แบบดอกปุ๋ยลับ | token ไม่คืน และบันทึกใน Audit Logs |
| แก้สูตรหลังมีคนปลูกแล้ว | แท็บสูตร แล้ว ตั้งค่างาน → คำนวณแบบดอกใหม่ทั้งหมด | ต้นเดิมจะยังใช้แบบเดิมจนกว่าจะกดคำนวณใหม่ ทำได้ก่อนวันเปิดผลเท่านั้น |

## วันเปิดผล

สวนบานเองเมื่อถึงเวลาที่ตั้งไว้ ไม่ต้องกดอะไร หน้าแปลงที่เปิดค้างไว้จะโหลดใหม่เองเมื่อนับถอยหลังครบ
ปุ่ม **เปิดสวนตอนนี้** ในแท็บตั้งค่างานใช้เปิดก่อนกำหนดเท่านั้น และย้อนกลับไม่ได้

## สิ่งที่ระบบรับประกัน

- หน้าตาดอกถูกกำหนดตอนปลูก แต่ API สาธารณะไม่ส่งแบบดอก รูปดอก หรือรูปหน้า ออกไปก่อนวันเปิดผล
  ยกเว้นแบบปุ๋ยลับที่เจ้าของต้นเลือกเอง ซึ่งเห็นได้เฉพาะเจ้าของ
- ปุ๋ยลับต้นละครั้ง ฐานข้อมูลบังคับเอง กดซ้ำหรือเปิดสองแท็บก็ไม่ถูกตัด token สองครั้ง
- การตัด token บันทึกใน Token Ledger พร้อมหมายเลขต้น
